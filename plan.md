# Task
Tugasmu adalah membuat web-app dengan dataset yang diberikan, dalam hal ini ada di folder data. EDA ada di folder notebooks. Kamu harus mempelajari struktur project saat ini, kemudian kamu diminta untuk membuat full stack crop-yield prediction berbasis web application dengan implementasi LLM dari Gemini (nanti aku berikan key nya di .env) dengan tech stack:
- Frontend: React, Vite, TailwindCSS
- Backend: FastAPI, Python, uvicorn sebagai swagger UI
- Machine Learning: Time-series Forecasting Model (yang paling cocok menurut EDA)
- LLM: Gemini-3-Flash-Preview (harusnya seperti itu kodenya)
Jadi, nanti user akan menginput fitur-fitur sesuai dengan fitur pada dataset yang diberikan, kemudian targetnya yaitu fitur 'hg/ha_yield'. User dapat menanyakan hasil tersebut kepada chatbot Gemini. Atur frontend UI dengan memperhatikan user experience. Pastikan user dapat menanyakan mengenai hasil prediksi "session" saat itu. Menu untuk membuat session baru sangat dianjurkan. Untuk prototype, project ini belum tersambung pada database, jadi tidak apa-apa kalau tidak ada historynya for now, nanti akan dilanjutkan pada tahap development berikutnya.

Setiap kali kamu menyelesaikan 1 tahap sub-task, kamu harus commit dan push ke GitHub.
